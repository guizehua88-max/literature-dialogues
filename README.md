# 文献对话阅读档案

十组文献阅读与高文波、王培坤论文的对话式静态阅读网页。

- 只收录用户指定的 12 个会话。比较重复导出，保留全部独有轮次，并优先选择公式保存更完整的相同答复。
- 支持手机、平板和电脑；会话目录、轮次目录、全文搜索、字号切换、深色阅读、当前设备阅读进度。
- 对话文字源自用户提供的导出记录。原附件、图片、部分文件下载并未包含在 TXT 导出中；不伪造或自动加载这些资源。
- 不依赖原 ChatGPT 账号，无登录、无分析追踪、无后端或付费服务。历史外部引用仅在点击后打开。
- index.html 包含阅读器、12 个会话、Markdown/公式排版依赖及字体，下载后可离线打开。
- GitHub Pages：main 分支 / (root)。搜索引擎 noindex 仅请求不索引，本仓库和网站仍是公开的。
- 原 AI 答复保持其历史含义，不代表已经完成新的科学事实复核。
